常见问题

  • 404：地址须以 /chat/completions 结尾（已自动补全，填到 /v1 即可）；模型名须与服务商控制台完全一致。
  • 401 / 403：鉴权失败，检查 API Key 是否正确、是否开通了对应模型。
  • 429：被限流或账户欠费。
  • 看图报错：确认模型支持视觉输入（名称带 vl / vision）；纯文本模型请先移除商品图。
